## 01-photo-pencil

```text
Use case: logo-brand. Asset type: Drawry mobile app icon concept, one 1024x1024 square raster artwork. Drawry is a private photo-and-drawing diary; its existing UI is pale lavender and purple. Design one original, polished, friendly icon for this product, readable at tiny launcher sizes. Flat front view, simple bold silhouette, large centered mark occupying about 60% of the canvas with safe margins. Full-bleed opaque square background, no pre-rounded outer corners, no device mockup, no lettering, no numbers, no caption, no watermark. Purple, lavender and warm ivory should harmonize with its existing UI. Concept: a warm ivory instant-photo frame with a simple purple sun and softly drawn landscape inside, a single short purple pencil integrated diagonally into the lower edge. Refined flat pictorial illustration, modest soft paper depth, only essential shapes. Convey recording a daily memory, not a generic camera application. Lavender full-bleed background.
```
