# Drawry 스케치북 디자인

방향: 사진으로 채우는 나만의 담백한 그림일기. iOS·Android 공통 디자인 원칙을 사용하되 시스템 선택기·인증·공유는 네이티브 동작을 유지합니다.

현재 구현을 기록한 문서이며 최종 디자인 승인 문서는 아닙니다. 아이콘·인트로·버튼·화면 아이콘·전체 화면 마감의 미완료 작업은 [TODO.md](../../TODO.md)에서 관리합니다.

## 스타일

- 바탕 `#F7F3EA`, 종이 `#FFFCF5`, 연필색 글자 `#302C29`, 보라색 포인트 `#78658F`.
- 다크 모드는 회갈색 종이와 밝은 글자로 대응합니다. 사진에 장식용 색조를 입히지 않습니다.
- 제목·빈 화면에 나눔손글씨 펜, 본문·폼·버튼에는 시스템 글꼴. 글꼴은 앱 안에 포함하며 실행 중 다운로드하지 않습니다.
- 외부 서비스의 로고·브랜드 자산은 사용하지 않습니다. 노트 그림은 각 플랫폼의 벡터 코드로 그립니다.
- 기존 아이콘 시안은 별도 검토 대상으로 남아 있으며 런처 아이콘은 변경하지 않았습니다.

## 화면

기록은 날짜 → 사진 캐러셀 → 제목·짧은 본문 순서입니다. 카드/2열/3열 선택은 설정에만 있으며 기존 선택값을 보존합니다. 작성 화면에서는 고정 높이 사진 캐러셀·썸네일로 사진을 선택하고 그 아래에 글을 씁니다. 사진이 10장이어도 사진 10장 높이만큼 스크롤할 필요가 없습니다. 날짜·기분·태그·함께한 사람·날씨와 원본 보관 옵션은 펼쳐서 입력합니다. 상단 저장으로 바로 완료할 수 있고 미리 보기는 선택 사항입니다.

상세 사진을 누르면 전체화면에서 확대·이동·좌우 넘김을 할 수 있습니다. 캘린더는 기록이 있는 날짜에 작은 사진을 보여줍니다. 공유는 사진 비율을 보존해 종이 안에 맞추며 기존 1:1/4:5/9:16·포함 항목·워터마크 설정을 유지합니다.

사진 꾸미기에서는 작업 영역을 고정하고 하단의 사진/필터/글자/낙서 도구를 전환합니다. 낙서는 6색·3굵기의 펜, 획 지우개, 실행 취소·다시 실행을 제공합니다. 한 손가락으로 그리고 두 손가락으로 확대·이동합니다. 사진 원본은 수정하지 않습니다.

데이터 계약은 [공통 규격](../../shared/specs/native-v2.md)의 편집 v2 절을 따릅니다. 기존 암호화·휴지통·복원 정책은 유지합니다.

## 안전한 검증

`drawry-sketchbook-qa`라는 전용 가상 기기에서만 샘플 기록을 추가하는 UI 테스트가 실행됩니다. 다른 가상 기기에서는 해당 테스트가 스킵됩니다. 샘플은 테스트 코드가 생성하는 풍경 도형이며 실제 사용자 사진을 사용하지 않습니다.

테스트 스크린샷은 QA 전용 테스트에서만 캡처 차단을 잠시 해제해 얻습니다. 앱 본체의 `FLAG_SECURE` 및 iOS 가림 처리는 그대로입니다. 수동 테스트 기기에 `connectedDebugAndroidTest`를 실행하거나 앱 데이터를 지우지 마세요.

이후 사용자가 같은 QA AVD에서 직접 테스트하고 [날짜별 공개 사진 샘플](../testing/showcase-data.md)도 추가했습니다. **현재의 `drawry-sketchbook-qa`는 자동 테스트용 빈 기기가 아닙니다.** AVD 이름 조건을 통과한다는 이유만으로 위 UI 시나리오를 다시 실행하면 안 됩니다. 현재 데이터 보호와 재개 방법은 [HANDOFF.md](../../HANDOFF.md)를 따릅니다.

검증 결과와 환경 제한은 [검증 상태](../../VALIDATION_STATUS.md)에 기록합니다. iOS 전체 앱 빌드·실기기 확인은 전체 Xcode가 있는 환경에서 별도로 통과해야 합니다.
