# 미디어 제한 검증 도구

앱 구현 언어와 무관하게 iOS·Android 실기기 측정 결과를 같은 규칙으로 판정하는 Node.js 도구입니다. 이 도구는 미디어를 직접 변환하지 않습니다. 각 플랫폼의 테스트 앱이 내보낸 측정 JSON을 검증하고 두 플랫폼의 최소 사양 기기가 모두 통과한 가장 큰 프로필을 추천합니다.

## 프로필

- `saving`: 미디어 5개, 영상 1개·30초, 150MB
- `balanced`: 미디어 10개, 영상 3개·총 60초, 300MB
- `expanded`: 미디어 20개, 영상 5개·총 180초, 1GB

프로필의 숫자는 테스트 부하이며 사용자 파일을 정확히 그 크기로 제한한다는 의미가 아닙니다. 실제 제한은 최소 사양 실기기 결과로 확정합니다.

## 사용법

```powershell
npm test
npm run new-report -- --platform android --profile balanced --model "test-device" --os "test-os"
npm run evaluate
```

생성된 `reports/*.json`에 플랫폼 테스트 앱이 측정한 값을 채웁니다. 판정기는 다음 조건을 모두 확인합니다.

- 가져오기, 암호화, 재열기, 피드, 수정, 공유, 백업·복원 성공
- 복원 후 무결성 일치
- 충돌과 메모리 부족 없음
- 평문 임시 파일과 취소 후 고아 파일 없음
- 저장 공간 사전 검사, 진행률, 취소와 반응형 UI 제공
- 피드의 썸네일 사용과 원본 동시 복호화 방지
- iOS·Android 최소 사양 실기기 결과 모두 존재

현재 저장소에는 앱 코드와 모바일 SDK가 없으므로 실기기 보고서는 아직 생성할 수 없습니다. 기술 스택을 선정하면 각 플랫폼 어댑터가 이 JSON 규격을 출력하도록 구현합니다.
